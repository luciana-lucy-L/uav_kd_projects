# 项目框架图规格说明（7 张）

> 层级：输出层。用于生成论文/汇报的框架图。
> 用法：把 §1 的视觉语言 + 需要的那一节（§2–§8）一起交给生成式 AI。
> 原则：**文字尽量少，靠颜色和形状区分"已有内容"与"我的工作"。**

---

## 1. 统一视觉语言（所有 7 张图必须一致）

### 1.1 颜色 = 归属

| 样式 | 含义 | 用在什么上 |
|---|---|---|
| 🟦 **蓝色实线框，浅蓝填充** | **已有 / 外部给定**（我没做，直接用的） | CERLAB 教师系统、Gazebo 仿真器、UAV 模型、走廊场景、v1 遗留数据与模型 |
| 🟧 **橙色实线框，浅橙填充** | **我的工作**（本研究实现的） | 数据采集改造、数据集、学生网络、五个臂、训练框架、评估工具、诊断实验 |
| ⬜ **灰色虚线框，白色填充** | **待定 / 可牺牲** | 第 5 臂、R4 保留实验 |

### 1.2 线型 = 信号性质

| 线型 | 含义 |
|---|---|
| **实线箭头** | 训练与部署都存在的数据流 |
| **虚线箭头** | **仅训练期存在**，部署时断开（教师监督信号） |
| **粗箭头** | 主数据流 |

### 1.3 全局要求

- 横版，白底，扁平风格，无阴影无渐变
- 中文标签，字号统一，**每个框最多 8 个字**
- 图例（Legend）固定放右上角，只含上面三种颜色
- 不要装饰性图标，不要 3D 效果

**用途**：方法章节。**整张图全是橙色**（全部是我的工作）。

**布局**：左输入 → 中主干 → 右三个头。

                    ┌───────────────┐
                    │  LSTM (T=8)   │

## 5. 图 4 — 五个臂的对照

**用途**：说明"唯一变量是教师给的监督信号"。

**布局**：五行，每行一个臂。每行左边是**灰化的相同底座**（表示不变），右边高亮该臂特有的部分。

```
                 相同底座（灰化）        │  教师监督（橙色高亮）      │  损失
  ────────────────────────────────────────────────────────────────────────
  BC        [Backbone+Goal+LSTM]  →  控制头  │  动作 u                │  MSE
  TrajKD    [Backbone+Goal+LSTM]  →  控制头  │  轨迹 τ + 动作 u       │  λ·L_traj + L_ctrl
                                  ╰→ 轨迹头(虚线)
  CtrlKD    [Backbone+Goal+LSTM]  →  序列头  │  控制序列 U            │  加权 MSE (H步)
  JointKD   [Backbone+Goal+LSTM]  →  序列头  │  轨迹 τ + 控制序列 U   │  λ_t·L_traj + λ_c·L_ctrl
                                  ╰→ 轨迹头(虚线)
  第5臂⬜   [Backbone+Goal+LSTM]  →  控制头  │  感知输出（待定）       │  待定
                                  ╰→ 感知头(虚线)
```

**必须体现**：
- **底座在五行里完全相同且灰化**——这是"公平对照"的视觉表达
- 只有"教师监督"这一列是彩色高亮的，形成一条视觉主线
- 第 5 臂整行灰色虚线

**不要**：不要重复画网络内部（用一个灰色方块代表即可）。

## 6. 图 5 — 三轴实验设计

**用途**：实验章节开篇。说明总共要做多少组、怎么比。

**布局**：一个 5×3 网格 + 一个正交的评估维度。

```
                 B 轴：学生容量（压缩）
              α=1.0      α=0.5      α=0.35
         ┌──────────┬──────────┬──────────┐
  BC     │    ●R2   │   ●R3    │   ●R2    │
  TrajKD │    ●R2   │   ●R3    │   ●R2    │   A 轴
  CtrlKD │    ●R2   │   ●R3    │   ●R3    │   知识层级
  JointKD│    ●R2   │   ●R3    │   ●R3    │
  第5臂  │    ⬜待定 │    —     │    —     │
         └──────────┴──────────┴──────────┘
                      ↓ 每个模型都要测
         C 轴：干净 / 噪声 / 模糊 / 亮度 / 对比度 / JPEG
```

**必须体现**：
- 三个轴分别标注它回答什么问题：
  - **A 轴（横看）**：蒸馏哪一层知识最有用？
  - **B 轴（竖看）**：压缩后哪一行掉得最慢？ → 标注"**教授指派题目**"
  - **C 轴（加扰动）**：哪一行最抗干扰？ → 标注"**实验室主轴**"
- 格子里标注在哪一轮完成（R2/R3）
- 图下方一行：**全网格做离线评估；仅约 8 个配置做部署评估**

**不要**：不要写具体指标数值。

              ↓

  ┌──────────┬──────────┬──────────┐
