> 层级：输出层。**本文件是"给生成式 AI 画图的说明书"，不是图本身。**

> **面向读者：指导教授。** 图上只呈现现象、机制假设、判别方法与结论分支，**不含任何面向自己的提醒、纪律条款或自我辩护式说明**。

## 1. 主张（唯一结论）

看图者 10 秒内必须得出：

> **v1 的三个学生模型都无法复现教师的转向能力；这个现象有三个互相竞争的解释；R1 用五个不采新数据的判别实验测出三者的相对权重，结论直接决定新数据怎么采。**

这张图要让教授看到的是**方法论**：面对一个失败现象，先把候选机制列全、再设计能把它们分开的实验，而不是直接换方法或直接加数据。

## 2. 画布与骨架

- **竖版偏方，4:3 或 16:12，纯白底**；输出分辨率按 300 dpi、长边 ≥ 5000 px
- 自上而下五带，整体是一个**收敛的漏斗**：现象 → 机制 → 实验 → 结论 → 后续验证

| 带 | 内容 | 高度占比 |
|---|---|---|
| **带 0** | 标题区 | 7% |
| **带 1** | 现象：教师与三个学生的部署行为差距 | 22% |
| **带 2** | 三个候选机制 M1 / M2 / M3 | 17% |
| **带 3** | 五个判别实验 T1–T5 | 32% |
| **带 4** | 结论 → 采集协议的映射 | 14% |
| **带 5** | 诊断与验证的分工（R1 诊断 ↔ W6 验证） | 8% |

- 带与带之间用**一个居中的粗下箭头**（宽 chevron 形）连接，共 4 个，宽度自上而下略微收窄，形成漏斗视觉
- 带 1 内部左右宽度权重 **55 : 45**；带 3 为五列等宽卡片

### 带 2 — 三个候选机制

区标题（深紫 `#6B3FA0` 粗体）：`② Competing Mechanisms  三个候选机制（可能同时存在，权重未知）`

三张等宽卡片横向并列，每张卡片四行，逐字：

| 编号 | 卡片标题 | `描述` | `能解释` | `不能解释` |
|---|---|---|---|---|
| M1 | `M1 · Class Imbalance`<br>`类别不平衡` | `转向样本仅约 12%，未加权 MSE → 梯度被直飞样本主导 → 幅值低估` | `BC 的"频率对、幅度小"` | `为什么 TrajKD 更差` |
| M2 | `M2 · Multi-modal Labels`<br>`标签多峰 / 目标不可观测` | `无目标输入，视觉相同的岔路帧对应左 / 右矛盾标签 → MSE 最优解 = 均值 ≈ 0` | `所有模型的整体压缩；闭环卡死` | `为什么 BC 频率还对` |
| M3 | `M3 · Auxiliary-loss Gradient Interference`<br>`辅助 loss 梯度干扰` | `轨迹 loss 主导共享 backbone，轨迹标签方差低（多为直飞）→ 抑制控制头输出方差` | `TrajKD / SelfRedWP 比 BC 更差` | `BC 自身的压缩` |

卡片配色：M1 橙 `#E1701C`、M2 紫 `#6B3FA0`、M3 青绿 `#2A9D8F` —— 每张卡片用该色作为**顶部 6 px 色条**与标题文字色，卡片主体为白底 + 该色 1.5 px 描边。
"能解释"一行前置 ✓（该机制主色），"不能解释"一行前置 ✗（灰色 `#9E9E9E`）。

### 带 3 — 五个判别实验

区标题（深灰蓝 `#40566B` 粗体）：`③ Discriminating Experiments  五个判别实验（W1–W2，全部使用 v1 既有数据与模型，不采新数据）`

五张等宽卡片横向并列。每张卡片自上而下五个区块，逐字：

**T1 卡片**
- 顶部 chip：`检验 M1 / M2`（半橙半紫底色）
- 标题：`T1 · 训练集自身复现测试`　小字 `Train-set reproduction`
- `做什么`：`加载 runs/bc_v002 的 best_model.pt，在训练集（非验证集）上前向推理，统计预测 yaw_rate std 与标签 std 的比值；在 is_turning=True 子集上单独统计；对 TrajKD / SelfRedWP 重复`
- `示意图`：分组柱状图（两组：训练集 / 验证集；每组三根柱），顶部一条教师基准虚线
- `判读`：`训练集也复现不了 → 不是数据量问题，指向 M1 或 M2`<br>`训练集能、验证集不能 → 是泛化问题`
- 底部条：`成本 半天　·　W1`

**T2 卡片**
- 顶部 chip：`检验 M2`（紫底）
- 标题：`T2 · 过拟合能力测试`　小字 `Overfitting capacity`
- `做什么`：`从训练集取 200 个 is_turning=True 样本，关闭 dropout / weight decay / 数据增强，在这 200 个样本上训练至收敛（或 500 epoch），检查最终训练误差与预测 yr_std`
- `示意图`：一条随 epoch 下降的训练误差曲线（空图，无数值）
- `判读`：`拟合不了（误差不趋近 0）→ 输入-标签映射本身矛盾 → M2 成立`<br>`能拟合 → 容量与优化没问题，指向 M1`
- 底部条：`成本 半天　·　W1`

**T3 卡片**
- 顶部 chip：`检验 M1`（橙底）
- 标题：`T3 · 损失加权 / 平衡采样`　小字 `Loss weighting & balanced sampling`
- `做什么`：`不改数据集，在现有 uav_kd_v002 上重训 BC。方案 A：转向帧 loss 权重 × (1 / 转向帧占比 ≈ 8)；方案 B：平衡采样，使每 batch 中转向帧占 50%。与原始 BC(v002) 对比 yr_std 与转向帧分层 MSE`
- `示意图`：三根柱的前后对比图（原始 / 加权 / 平衡采样），加一条 0.20 的目标水平虚线
- `判读`：`yr_std 显著回升（如 0.104 → 0.20+）→ M1 成立，且顺带得到一个廉价修复手段`<br>`无明显变化 → M1 不是主因`
- 底部条：`成本 1–2 次训练（每次 2–3 h）　·　W2`

**T4 卡片**
- 顶部 chip：`检验 M2`（紫底）
- 标题：`T4 · 近邻标签方差测试`　小字 `Nearest-neighbour label variance`
- `做什么`：`用 runs/bc_v002 的 backbone 提取全训练集 1280 维特征；对每个 is_turning=True 样本，在其他 episode 中按余弦相似度检索 top-k 近邻；统计近邻对之间的 |Δyaw_rate| 分布；抽取相似度最高但标签差异最大的 20 对做人工目视确认`
- `示意图`：散点图，横轴 `余弦相似度`、纵轴 `|Δyaw_rate|`，右上角用虚线圈出"高相似度 + 大标签差异"区域
- `判读`：`高相似度对中存在大量符号相反的标签 → M2 成立，必须加目标输入`<br>`近邻标签基本一致 → M2 不是主因`
- 底部条：`成本 半天　·　W1`

**T5 卡片**
- 顶部 chip：`检验 M3`（青绿底）
- 标题：`T5 · 辅助 loss 梯度干扰测试`　小字 `Auxiliary-loss interference`
- `做什么`：`用相同数据重训 TrajKD，λ_traj ∈ {1.0（原值）, 0.1, 0.01}，对比各配置的验证期 / 部署期 yr_std`
- `示意图`：折线图，横轴 `λ_traj`（对数刻度，三个点）、纵轴 `yr_std`，加一条 BC 水平参考线
- `判读`：`λ_traj 越小、yr_std 越接近 BC → M3 成立，是 loss 平衡问题而非方法问题`<br>`与 λ 无关 → M3 不是主因`
- 底部条：`成本 2 次训练　·　W2`

**卡片统一样式**：白底、圆角 8 px、1 px 浅灰描边；顶部 chip 为该卡片检验的机制配色；`示意图`区块为浅灰底 `#FAFAFA` 的小画布，**内部只画坐标轴与曲线/柱形的形状，不标任何具体数值**；`判读`区块的两行分别以 ✓ / ✗ 起首但用中性灰色，不预设哪一条会成立。

### 带 4 — 结论 → 采集协议

区标题（深蓝黑粗体）：`④ From Diagnosis to Collection Protocol  诊断结论如何决定采集协议`

四个横向排列的分支框，逐字：

| 编号 | 条件（框头） | 采集协议 | 其他行动 |
|---|---|---|---|
| A1 | `若 M1 为主`（橙色框头） | `刻意采集转向密集 episode：多岔路目标、S 形、往返掉头；目标转向帧占比 ≥ 30%` | `训练默认启用平衡采样 / 损失加权` |
| A2 | `若 M2 为主`（紫色框头） | `目标点记录为必需；数据量可以不大，但目标覆盖度要高 —— 同一走廊配多个不同目标` | `目标条件化是核心修复手段` |
| A3 | `若 M3 为主`（青绿框头） | `与采集无关` | `R2 必须做 λ 敏感性扫描` |
| A4 | `若为混合（最可能）`（深灰框头，**框宽为前三者之和的视觉强调**或加粗边框） | `三条合并执行` | `三种手段同时启用` |

## 10. 历史踩坑（**必须与 §1–§7 一起粘给生成模型**）

以下是本项目其它框架图生成时反复出现的错误，本图同样适用：

1. **自行添加未要求的元素**。凡 §3 未列出的元素一律不画。
2. **自行修改或补全数字**。所有数值必须逐字照抄，模型不得"合理化"、不得为示意图编造数据点。
3. **把示意图画成真实结果**。五个示意图必须是空的形状，标注 `示意 schematic`，否则教授会误读为已有结论。
4. **连线画错或画多**。本图只有四个居中的漏斗箭头，机制与实验之间靠颜色对应，不画连线。
5. **配色蔓延**。橙 / 紫 / 青绿三色只用于机制及其对应实验；标题、正文、表格、漏斗箭头一律中性色。
6. **视觉权重失衡**。三个机制、四个结论分支必须等权呈现，不得因为"M2 看起来更可能"就把它画得更大更醒目。
