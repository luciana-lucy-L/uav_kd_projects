## 3. 决策门

每轮末必须做出明确判定并记入 `50_records/50_log.md`。

### 🚪 G0（W2 末）诊断结论是否明确

- ✅ 三个机制的相对贡献可解释 → 定稿采集协议，进入采集
- ❌ 结果互相矛盾 → **暂停，加一周深挖**。不要带着不清楚的诊断去采数据

### 🚪 G1（W6 末）**全项目最大的单点风险**

> **目标条件化（+ 诊断得出的修复手段）后，部署时 yaw_rate std 是否显著回升？岔路口能否正确转向？**

- 建议判据：yr_std ≥ 0.20（教师 0.340 的约 60%），且岔路口转向选择显著优于随机
- ✅ 通过 → 进入 R2
- ❌ 不通过 → **立刻停止，不要进 R2**。此时还剩 15 周，转向空间充足。备选手段：多假设输出（R-WTA，Loquercio 式）、轨迹词表分类（Racing distillation 式）

### 🚪 G2（W11 末）各知识臂是否有可测差异

- ✅ 有差异 → 正结果叙事推进 R3
- ❌ 无差异 → **切换为"可蒸馏性边界"负结果叙事**。R3 实验内容不变，只换论述框架
- **这个门只决定"怎么写"，不决定"做不做"**

### 🚪 G3（W16 末）容量轴与知识轴是否有交互效应

- ✅ 有交互 → 压缩轴成为主贡献之一，是论文最强结论
- ❌ 无交互 → 改为"我们验证了知识类型与容量无交互"（仍是对教授题目的正当回答），鲁棒性轴顶上做主结论

## 5. 风险与缓冲

### 缓冲总量

| 来源 | 量 |
|---|---|
| 各轮内嵌弹性（R1 1 周 / R2 0.5 周 / R3 0.5 周） | 2 周 |
| 年末年始（W17） | 1 周 |
| R4 补跑周（W19） | 1 周 |
| R4 保留项周（W18，可牺牲） | 1 周 |
| **合计** | **约 5 周 ≈ 24%** |

### 四个最可能触发重做的点

| 风险 | 防护 |
|---|---|
| **采集协议有遗漏 → 全量重采** | W3 先试采 2 个 episode 跑通全管线（省钱最多的一步） |
| **G1 不通过（诊断错误）** | W1–W2 先做 T1–T5，W6 就暴露，还剩 15 周 |
| **部署评估机时爆炸** | W2 完成批量部署脚本；全程约 120 次飞行，手动跑必然超时 |
| **α<1.0 从头训练不收敛** | W9 压缩探针提前 3 周暴露 |

### 其他技术风险

| 风险 | 概率 | 应对 |
|---|---|---|
| 补齐 goal+LSTM 后各 KD 臂差距消失 | 🔴 高 | 提前把**样本效率**和**新路线泛化**作为主指标，不只看最终 SR |
| 采集后转向/岔路情形仍覆盖不足 | 🟠 中 | 采集协议明确要求岔路口、多目标、往返 |
| LSTM 训练不稳 / 序列构造出错 | 🟠 中 | 先用 T=8 小窗口验证管线 |
| ~~FeatKD 的"教师表征"无合理定义~~ | — | **已解决（2026-09-07）**：FeatKD 方案否决；教师感知模块有真实输出可蒸馏（`2D_occupancy_map` / `tracked_bboxes`）。第 5 臂改为待定，R1 后决策（`20_architecture/20_architecture.md` §3.2） |
| DAgger 闭环不稳定 | 🟠 中 | 按 Loquercio 做法逐步放宽跟踪阈值 |

### 论证风险

| 风险 | 应对 |
|---|---|
| 审稿人问"这不就是 LBC / Loquercio 换平台" | Introduction 前两段正面区分并引用。v1 连这些文献都没引，是最紧急的缺口 |
| 审稿人问"为什么不用 VT&R" | 用动态障碍物差异回答，需实验支撑 |
| "消融研究"被认为贡献不足 | 写成**方法论贡献**："以可分解教师作为研究工具测量知识层级的可迁移性" |
| 仿真-only 被质疑 | 明确写成 simulation study，不使用 "practical / real-world ready" 之类措辞 |

## 7. 论文写作节奏

**不把写作压到 R4。** 每轮末花 2–3 天写对应章节：

| 轮次 | 章节 | 完成周 |
|---|---|---|
| R1 | 引言 / 相关工作 / 教师系统 / 数据集 / 学生架构 / **诊断分析** | W6 |
| R2 | 蒸馏方法 / 实验设置 / 知识层级结果 | W11 |
| R3 | 压缩结果 / 扰动鲁棒性结果 / 讨论 | W16 |
| R4 | 结论 / 限制 / 未来工作 + 全文润色 | W21 |

**诊断分析（R1 产出）本身是论文的一个章节**，不是前期调试的副产品——它是本研究方法论严谨性的直接体现。
