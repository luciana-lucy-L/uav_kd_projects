# 周会汇报材料

> 层级：计划层。**每周会前填写，会后补记录。**
> 这是**每周汇报的唯一文件**。排期见 `30_plan/31_schedule.md`，实验数据见 `50_records/50_log.md`。

---

## 怎么用

每周会前 15 分钟，按模板填一节，倒序放在最上面。内容从两处取：

| 取什么 | 从哪取 |
|---|---|
| 本周计划做什么 | `30_plan/31_schedule.md` 对应周次的任务表 |
| 实际做出什么数字 | `50_records/50_log.md` 本周的实验条目 |
| 遇到什么问题 | `50_records/51_issues.md` |

---

## 模板

```markdown
## W?（MM-DD – MM-DD）— <一句话主题>

**轮次**：R?　**本周状态**：✅按计划 / ⚠️滑动 / 🔴受阻

### 1. 本周做了什么
- （3 条以内，动词开头）

### 2. 关键结果
| 指标 | 值 | 对照 |
|---|---|---|
| | | |

（或一张图，路径写清楚）

### 3. 结论
（一句话：这个结果对研究问题意味着什么）

### 4. 问题 / 需要教授决策的事
- （没有就写"无"）

### 5. 下周计划
- （对齐 31_schedule.md）
```
