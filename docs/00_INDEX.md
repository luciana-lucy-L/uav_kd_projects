# 文档索引与维护规则

> 本文件是所有文档的地图。**新增文档必须先在这里登记。**
> 最后更新：2026-09-07（v2 文档体系建立；按段位拆分为文件夹）

---

## 1. 命名规范

**十位数分层，个位数留空生长。数字越大，变更越频繁。**

| 段位 | 层 | 变更频率 | 谁在什么时候改 |
|---|---|---|---|
| `00` | 索引 / 上手 | 极低 | 新增文档时 |
| `10–19` | **研究层** | 极低 | 研究方向变更时（每轮最多一次） |
| `20–29` | **架构层** | 低 | 模型/数据结构变更时 |
| `30–39` | **计划层** | 中 | 轮次切换、进度调整时 |
| `40–49` | **实验层** | 中 | 新增实验臂、评估协议变更时 |
| `50–59` | **记录层** | 高 | 每次实验、每次踩坑 |
| `60–69` | **输出层** | 中 | 出图、写论文素材时 |
| `_archive/` | 归档 | 只读 | 永不修改 |

**核心原则：改一件事只需要改一个文件。**
研究方向变 → 只改 `10`；进度滑 → 只改 `31`；加一个实验臂 → 只改 `40`。

**每个段位一个文件夹：**

```
docs/
├── 00_INDEX.md          本文件（文档地图）
├── 00_ONBOARDING.md     新会话/新人快速上手
├── 10_research/         研究层
├── 20_architecture/     架构层
├── 30_plan/             计划层
├── 40_experiments/      实验层
├── 50_records/          记录层
├── 60_outputs/          输出层
└── _archive/            归档（只读）
```
